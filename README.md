# Red-Black-Tree-Implementation-DSA
Description
This project provides a basic implementation of a Red-Black Tree (RBT) in C++. Red-Black Trees are self-balancing binary search trees that ensure efficient insertions, deletions, and lookups in O(log n) time.

Features
Node insertion with automatic rebalancing

Tree rotation (left and right)

Violation fixing to maintain red-black properties

In-order traversal

Red-Black Tree Properties
Each node is either red or black.

The root is always black.

All leaves (NIL or null children) are black.

Red nodes cannot have red children.

Every path from a node to its descendant NULL nodes has the same number of black nodes.
